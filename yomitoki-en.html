Yomitoki

Re-measure what the AI told you.

Use “AI reply” for answers you got from an AI yourself, and “Any text” for everything else.

Checks for an AI’s made-up personal stories and relationships, unsupported assertions, and excessive agreement.

How to use / API key

No API key needed. You can run up to 3 inspections a day for free (the count resets at midnight Japan time). Your text is sent through Yomitoki’s server to Google’s Gemini for the inspection. The server does not store your text.

Get a Gemini key from Google AI Studio and paste it here. With a free-tier Gemini key, you may see errors such as “Gemini is busy” or “usage limit reached.” If that happens, wait a moment or switch to Free. Usage limits and charges depend on your Google settings. Your key is stored in this browser and used only to authenticate with Google’s API. On a shared device, clear the key field when you finish.

No API key needed: you can inspect up to 3 texts a day for free. If you have your own Gemini API key, add it in the settings for unlimited use.

If you have the original question or relevant conversation, include it here. Otherwise, only the response itself will be inspected.

Selecting “Re-measure” sends your question or context, the text, and the proposed revision to Google’s API for analysis. Viewing the sample makes no API call.

Inspection results are an AI assessment.

Unsupported assertion Excessive affirmation Overconfident prediction Unsourced citation

Superscripts label the kind of passage: F = Fact, I = Inference, O = Opinion, E = Encouragement, Q = Question or conversation prompt. “Fact” means a verifiable statement, not a claim verified as true. Colored underlines mark issues. When a passage has several issues, its underline shows one color; every issue remains listed below. If “Unsupported assertion” overlaps with a more specific issue, the more specific issue supplies the color. Colors do not rank severity.

Re-measured reply

Yomitoki inspects AI replies using four kinds of statement and four kinds of issue: fact, inference, opinion, encouragement; unsupported assertion, excessive affirmation, overconfident prediction, and unsourced citation. It revises the reply without assigning scores.
